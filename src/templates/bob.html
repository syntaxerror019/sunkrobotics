BOB ROV

BOB ROV IS CURRENTLY IN DEVELOPMENT. RESOURCES ON THIS PAGE ARE SUBJECT TO CHANGE

Design Purpose

BOB ROV was conceived as a general deep sea underwater platform, allowing operations at 500 meter depths. A modular design will allow BOB ROV to be outfitted with tools for roles such as exploration, sea bed sampling, infrastructure installation and repair.




Technical Specifications

Enclosure
  • The enclosure consists of end caps bolted to flanges welded to a ⅜" thick tube with a 6" OD.
  • All metal components on the ROV's exterior are made of 316 stainless steel to avoid rust and galvanic corrosion
  • Each end cap is sealed using a primary face seal O-Ring and 2 secondary radial O-Ring seals
End Cap Seal
  • The face seal is compressed using sixteen ¼ 20 bolts with skewed thread lock nuts.
  • The radial seals were designed using the Parker Radial Seal Design Guide
  • The face seal was designed using ORD 5700: Parker O-Ring Handbook
  • The Radial O-Rings are EPDM (AS-568) size 352 from Gallagher Seals
  • The Face O-Rings are EPDM (AS-568) size 354 from Gallagher Seals
External Frame
  • Split collars built into the flanges hold .115" thickness 1" OD tubes which serve as handles, cable channels, and mounting points
  • The thrusters are bolted to their mounts using four M3 screws. These mounts are connected to the flange with two 10-24 bolts
  • Curved ⅛" steel thruster housings are affixed by being sandwiched between the thrusters and their mounts
  • Thruster guard design is yet to be determined but will likely feature a metal mesh
Camera Window
  • Round 10mm thickness, 50mm OD sapphire window
  • The Window Face O-Ring is EPDM (AS-568) size 322 from Gallagher Seals
  • The Window Housing is connected to the front end cap using sixteen 10-24 bolts
